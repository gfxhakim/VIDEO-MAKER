# AutoClip Studio – frontend

Next.js (App Router) + Tailwind CSS v4 + shadcn/ui components (in `components/ui`).

```bash
cp .env.example .env.local   # NEXT_PUBLIC_API_URL=http://localhost:8000
npm install
npm run dev                  # http://localhost:3000
```

Pages: `/` dashboard + new run, `/projects/[id]` clips, `/review`, `/music`, `/publish` (accounts), `/publish/queue`.
