Caption fonts live here (they are git-ignored). Download the defaults with:

    python scripts/download_fonts.py

All defaults are open-source (SIL Open Font License): Montserrat, Anton, Bebas Neue,
DM Serif Display, Poppins. Drop any extra `.ttf`/`.otf` here and reference its family
name in `app/presets/caption_styles.json`.
