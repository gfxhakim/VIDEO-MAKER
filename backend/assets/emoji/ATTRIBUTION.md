Emoji artwork uses Apple Color Emoji (iOS / macOS 26, Unicode Emoji 16.0) extracted at 96px RGBA PNG
with Apple emoji-datasource fallback for multi-codepoint ZWJ sequences.
All files are stored as `<codepoints>.png` (lowercase hex joined with `-`, without `fe0f`).
Refresh or extract additional emojis with `python scripts/download_emojis.py`.
